# AI adapter review — disabled, 23 November 2026

Both existing Superbrain text-generation entry points now use paid-ai.ts. The legacy enable flag cannot bypass the ledger: no current server-owned cost contract means no provider call. Existing evidence-based fallbacks remain available. No health record, credential, prompt or generated text is stored in budget tables. No action tools are added.

Before each attempt: validate exact configured provider/model, UTF8 input-byte limit, output-token limit, pricing/routing/FX evidence expiry (maximum24hours), and a positive maximum all-in USD charge converted upward to SGD cents. Atomically reserve from the weekly AI category. A denied/ambiguous/replayed reservation never calls the provider. SDK retries are disabled; Gateway provider routing is restricted to one provider and no model fallback list. This is not proof that a provider never performs internal retries or charges on failures.

The reservation now atomically retains the reviewed pricing/routing/FX contract. After generation: validate and persist Gateway generation ID through service-only gb_budget_note_receipt before cost lookup. The version-matched Gateway SDK validates the generation lookup response. Lookup uses the same bounded Gateway client/auth configuration as generation, no-store/no redirects. Only matching generation/model/provider, non-BYOK and finite nonnegative billed USD cost can settle. Verified USD micro-units and billing timestamp are retained; SGD settlement is computed in the database from the reservation’s stored FX ceiling. Charges cannot be attributed earlier than their reservation week, and a post-midnight Monday bill stays in the new week. The configured FX/fee ceiling is conservatively rounded upward; this is not final bank-statement reconciliation. Missing receipt, timeout, billing ingestion delay, mismatched route or DB failure keeps the reservation held. No automatic release, retry or inferred zero cost. Overruns within the ledger's integer range are preserved and halt further paid reservations. An unrepresentable/malformed cost remains unresolved, requiring investigation before activation or further billing reconciliation.

The pending receipt is unique, immutable through the RPC and must match settlement. It enables manual recovery after process interruption without storing prompts. If the process dies before saving an ID or the provider charges despite throwing before a result, the hold has no provider identifier; reconcile against provider records rather than assuming free. No new recurring reconciliation job is enabled.
